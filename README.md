# AI Auto Email Reply Generator

An AI-powered email reply generator built using Spring Boot, Angular, and Gemini API.

## 🚀 Live Demo

[Open AI Auto Email Reply Generator](https://ai-auto-email-reply-generator.vercel.app/)

## 🛠️ Technologies Used

* Java
* Spring Boot
* Angular
* TypeScript
* Gemini API
* HTML
* Bootstrap

## 📌 Project

This project generates AI-based email replies from the given email content.

### Frontend

Deployed using Vercel.

### Backend

Deployed using Render.
